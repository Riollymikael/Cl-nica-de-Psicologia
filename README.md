## 📌 Sobre o Projeto

Uma landing page moderna, acolhedora, altamente conversiva e 100% responsiva para a clínica **Psicologia & Vida**, desenvolvida para apresentar atendimento psicológico especializado, abordagem terapêutica humanizada e agendamento prático de sessões.

### ✨ Diferenciais do Layout:
* ⚡ **Hero Section:** Chamada para ação (CTA) estratégica com agendamento rápido via WhatsApp.
* 👩‍⚕️ **Sobre a Profissional:** Apresentação da psicóloga, CRP e abordagem terapêutica.
* 🛋️ **Especialidades:** Apresentação clara das modalidades de atendimento (Ansiedade, Depressão, TCC, Terapia de Casal, etc.).
* 💬 **Depoimentos:** Prova social e relatos que transmitem acolhimento e confiança.
* 📱 **Layout Responsivo:** Perfeito para desktops, tablets e smartphones.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica e acessível.
* **CSS3:** Design moderno, CSS Grid, Flexbox e animações suaves.
* **JavaScript:** Interatividade e validações.
